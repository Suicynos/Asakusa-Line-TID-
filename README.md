# 都営浅草線 列車走行位置 PWA

ODPT（公共交通オープンデータセンター）の `odpt:Train` / `odpt:TrainInformation` を使い、
都営浅草線の在線状況を横スクロールの駅並びで表示するプロトタイプです。

## 使い方

1. `index.html` をそのままブラウザで開くか、簡易サーバーで配信してください。
   ```
   npx serve .
   ```
2. 画面右下の歯車アイコンから、ODPT Developer サイトで取得した consumerKey を入力すると
   実データで動作します。未入力の場合はサンプルデータで見た目を確認できます。

## 実装済みの仕様（これまでの検討内容の反映）

- レーン: 押上方面＝上段 / 西馬込方面＝下段（`odpt:railDirection` で判定）
- 列車位置: 停車中は駅の位置、駅間走行中（`odpt:toStation` あり）は出発駅と次駅の中間に固定表示（滑らかな補間はしない）
- 複数本重なり: 縦スタック。1〜2本はそのまま表示、3本以上は「+N本」に畳んでタップで全展開
- 列車種別ごとの色分け（背景色＋白文字。9種別。快特／快速特急は同色、
  アクセス特急／エアポート快特は同色）
- 遅延: `odpt:delay`（秒）を分に変換し、1分以上のみ吹き出しで表示
- 回送・不明種別: グレーの電車アイコンのみ（バッジなし）
- 行き先: 他社線データ欠損などで解決できない場合は行き先欄自体を非表示
- 異常時: `odpt:TrainInformation` を都営分のみフィルタし、平常運転以外なら
  画面上部に赤帯バナーを全幅固定表示
- ナビゲーション: 前の駅／次の駅ボタンやページネーションは廃止し、横スクロールのみ
  （スクロールバー非表示）
- ポーリング: 列車位置15秒間隔、運行情報90秒間隔
- ヘッダー左上は浅草線の公式シンボル（コーラルレッドの輪＋白背景＋黒太字A）を模したアイコン、
  右上に秒単位の最終更新時刻

## 未確認・要検証の点

- **`odpt:railDirection` の実際の値**: `stations.js` の `DIRECTION_LANE` は
  `odpt.RailDirection:Oshiage` / `odpt.RailDirection:NishiMagome` を仮定していますが、
  実際のAPIレスポンスで一致するか要確認です。異なる場合はここを修正してください。
- **`odpt:trainType` のID**: 同様に `TRAIN_TYPE_STYLE` のキーは一般的な命名慣習からの推測です。
  特に「快特」（京急方面）に対応するIDは複数の候補があり得るため、実データで確認・調整が必要です。
- **境界駅での欠測**: 押上駅など管轄が別会社の駅では列車位置が取得できないことがあります
  （仕様として割り切り、注記は出していません）。
- **APIレート制限とプロキシ**: 15秒間隔でのポーリングをそのままクライアントから直接APIへ
  投げる設計になっています。複数ユーザーでの運用を想定する場合は、サーバー側で
  短時間キャッシュするプロキシを挟むことを推奨します（consumerKeyをクライアントに
  埋め込まない、という意味でもプロキシ推奨です）。
- **京急・京成・北総の運行情報**: 対象外（都営浅草線区間内のみ）です。京急側は
  「チャレンジ2026限定ライセンス」の可能性があり、恒久的な組み込みには別途ライセンス確認が必要です。
- アイコン画像はプレースホルダーとして自動生成したものです。東京都交通局の公式シンボルを
  そのまま使う場合は、利用規約を確認のうえ正式な画像に差し替えてください。
